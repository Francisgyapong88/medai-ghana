# Figma Make Prompt

**Project Title:**
**AI-Based Medical Diagnostic Assistant for Rural Clinics in Ghana**

## Project Overview

Design a modern, professional, responsive web application for healthcare workers in rural clinics in Ghana. The application is an AI-powered clinical decision support system that helps healthcare professionals perform **preliminary assessments** for five diseases:

* Malaria
* Typhoid Fever
* Pneumonia
* Diabetes
* Hypertension

The system is **NOT** intended to diagnose patients independently. Every prediction must clearly display a disclaimer that it is only an AI-assisted recommendation and must be verified by a qualified healthcare professional.

The design should follow modern medical UI/UX principles similar to Google Health, Microsoft Healthcare, Epic Systems, WHO dashboards, and modern SaaS healthcare platforms.

# Overall Feel

The application should look like a real production-ready healthcare SaaS platform that could be used by the Ghana Health Service. The interface should inspire trust, professionalism, simplicity, and efficiency. Use clean cards, subtle gradients, soft shadows, modern charts, and intuitive workflows. The design should be polished enough to hand directly to frontend developers for implementation using React, Tailwind CSS, and FastAPI.
